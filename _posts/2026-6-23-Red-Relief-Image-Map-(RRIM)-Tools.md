# Red Relief Image Map (RRIM) Tools for ArcGIS Pro  
### High‑Performance, Dependency‑Free Terrain Visualization

![RRIM Banner](https://raw.githubusercontent.com/Darren-Thornbrugh/RRIM_Toolbox/main/rrim-banner.png)

The **RRIM Toolbox** is now available as a fully ArcGIS Pro–native Python toolbox designed for high‑resolution terrain visualization in geomorphology, archaeology, hydrology, and landscape analysis.

This release provides:

- **Native Topographic Openness (POS/NEG)**
- **Openness Index (POS–NEG)**
- **Slope from DEM**
- **Red Relief Image Map (Custom)**
- **Red Relief Image Map (Classic)**

All tools run inside ArcGIS Pro’s default Python environment using only NumPy and GDAL already bundled with Pro — **no external installs, no conda, no RVT dependency**.

## 🛰️ About RRIM

Red Relief Image Maps combine openness, slope, and color‑mapped blending to produce high‑contrast terrain visualizations ideal for scientific analysis and publication‑quality figures.  
This toolbox implements both **modern Cividis‑based RRIM** and **classic red‑on‑gray RRIM** with optimized, tiled GeoTIFF output.
